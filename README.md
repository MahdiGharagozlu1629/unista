## 📖 About

**UNISTA** is a university-focused social networking platform designed to connect students in a modern and secure environment.

It allows students to communicate, share posts, follow each other, and interact with the university community in a familiar social media experience.

---

## ✨ Features

- 👤 User Authentication
- 📝 Create Posts
- 🖼️ Multiple Image Upload
- ❤️ Like Posts
- 💬 Comments
- 👥 Follow / Unfollow Users
- 📱 Responsive Design
- 🌙 Dark Mode UI
- 🔒 Secure Authentication

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/MahdiGharagozlu1629/unista.git
```

Go to project

```bash
cd unista
```

Install dependencies

```bash
composer install
```

Copy environment file

```bash
cp .env.example .env
```

Generate application key

```bash
php artisan key:generate
```

Configure your database inside `.env`

Run migrations

```bash
php artisan migrate
```

Create storage link

```bash
php artisan storage:link
```

Start the development server

```bash
php artisan serve
```
